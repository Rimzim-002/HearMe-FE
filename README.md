## 🟣 HearMe — Anonymous Support & Listening Platform

HearMe is an anonymous platform that connects people who want someone to talk to (Seekers) with trained listeners who are ready to help. It is built around safety, privacy, and clear communication — without offering therapy, clinical treatment, romantic matchmaking, or partner-seeking interactions of any kind.

# 🌟 What HearMe Is

✔ A safe digital space to talk

✔ Anonymous, non-judgmental interactions

✔ Trained listeners who provide supportive conversation

✔ A structured, moderated platform with clear rules


# 🚫 What HearMe Is NOT

- Not therapy, counseling, or professional mental-health treatment

- Not a dating or romance platform

- Not a space for finding life partners or emotional attachments

- Not a place to seek clinical advice, diagnoses, or emergency intervention

##🧑‍🤝‍🧑 User Roles
# 🟣 Seeker

- People looking for someone to talk to in a private, anonymous environment.

- Capabilities

- Join without sharing personal data

- Talk freely and comfortably

- Access community safety guidelines and crisis resources

# 🟣 Listener

- Trained individuals offering empathetic, supportive conversations.

- Requirements

- Must upload credentials (PDF/image)

- Admin verification approval is required

- Must follow safety and communication guidelines

# 🟤 Admin

- Responsible for safety, verification, and moderation.

- Responsibilities

- Review and approve listener credentials

- Handle reports and violations

- Maintain a safe, respectful community space

# 🛡️ Safety & Privacy

- HearMe prioritizes a secure environment:

- Anonymous access for Seekers

- Moderation and reporting tools

- Clear boundaries for conversation

- Crisis resources and emergency guidance

- No personal data exchange allowed

# 🚀 Tech Stack

- Framework: Next.js 14 + TypeScript

- Styling: Tailwind CSS

- Animations: Framer Motion

- Authentication: JWT with anonymous device tokens

- State Management: React Context API

- File Handling: Base64 listener credential uploads

# 📦 Installation
git clone https://github.com/Rimzim-002/HearMe-FE.git
cd HearMe-FE
npm install
npm run dev

# ⚙️ Environment Variables

Create a .env.local file:

NEXT_PUBLIC_API_URL=your_api_url_here
NEXT_PUBLIC_APP_NAME=HearMe
